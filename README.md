# 守界 · 冲突力训练

帮「老实人」把退让、压抑、自我归因，练成温和坚定的职场冲突处理能力。

## 怎么用

用浏览器直接打开 `index.html` 即可，数据保存在本地 `localStorage`。

```bash
open index.html
# 或
python3 -m http.server 8765
# 然后访问 http://localhost:8765
```

## 功能

1. **照镜**：6 题自评，识别三种逃避模式（退让 / 压抑 / 自我归因）
2. **演练**：6 个职场情景，先选本能反应，再写自己的回应并对照示范
3. **话术**：可复制、可收藏的温和坚定句式
4. **复盘**：把没说出口的冲突写成可改进的练习
5. **原则**：四条心法 + 恶性循环提醒

## 设计理念

善良 ≠ 软弱。目标不是变得尖酸刻薄，而是：**清晰、尊重、不讨好**。
